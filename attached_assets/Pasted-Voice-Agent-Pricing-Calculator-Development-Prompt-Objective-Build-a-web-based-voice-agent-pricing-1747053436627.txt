Voice Agent Pricing Calculator - Development Prompt
Objective: Build a web-based voice agent pricing calculator that calculates the total cost of running voice AI conversations based on various API services and infrastructure costs.
Calculator Structure
1. Input Parameters
Create input fields for the following API costs:
* Transcription cost per minute (default: $0.0065)
* LLM input token cost (default: $0.000002)
* LLM output token cost (default: $0.000008)
* Voice model cost per character (default: $0.000037375)
* vCPU cost per minute (default: $0.00007083333)
2. Calculation Assumptions
Create adjustable input fields for these assumptions:
* Spoken words per minute (default: 100)
* Tokens per word (default: 1.3)
* Characters per word (default: 6)
* Turns per minute (default: 4)
* LLM vs user speech ratio (default: 0.5, meaning LLM speaks 50% of the time)
3. Conversation Parameters
Create input fields for:
* Conversation length in minutes (default: 10)
* Number of agent processes per vCPU (default: 1)
Calculation Logic
1. LLM Token Calculations
LLM Input Tokens formula:

(spoken_words_per_minute * tokens_per_word / turns_per_minute) * (turns_per_minute * conversation_length) * (turns_per_minute * conversation_length + 1) / 2
LLM Output Tokens formula:

spoken_words_per_minute * tokens_per_word * llm_speech_ratio * conversation_length
2. Cost Calculations
* Transcription cost = transcription_cost_per_minute * conversation_length
* LLM cost = (llm_input_tokens * llm_input_token_cost) + (llm_output_tokens * llm_output_token_cost)
* Voice cost = voice_cost_per_character * spoken_words_per_minute * characters_per_word * (1 - llm_speech_ratio) * conversation_length
* Hosting cost = (vcpu_cost_per_minute * conversation_length) / agents_per_vcpu
* Total cost = Transcription cost + LLM cost + Voice cost + Hosting cost
* Cost per minute = Total cost / conversation_length

3. Output Display:

4. Additional Features:

    * Add ability to save/load different pricing scenarios
